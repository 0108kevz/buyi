# 《默毀》第一關自檢報告（N4）

檢查對象：`成品/默毀-第一關-灰盒.html`（第一版）
方法：逐條對驗收標準 2（線索設計與敘事引導）與標準 4（反派塑造與線索一致性）。這兩條的檢查人是 AI 協同系統，由我自檢；標準 1、3 要真人在螢幕前玩，我驗不到，留給 N5 老闆試玩。

## 一、標準 2：線索設計與敘事引導

線索清單與各自指向：

| 線索 | 內容 | 指向 |
|---|---|---|
| 川堂公告欄《校史節錄》 | 戰前此地為亂葬之崗，窪地聚氣，僅以土方填平 | 反派力量的來源（陰氣），印證主題 |
| 教室甲黑板 | 情侶殉情，男方沒跳，只有她從頂樓跳下去 | 反派的身分、死法、出沒樓層 |
| 川堂東側大窗 | 操場東側隆起的土丘、寸草不生 | 印證公告欄：亂葬崗的地貌殘留還在 |
| 教室乙課桌字條 | 姐姐在查那個女生的名字，名字被塗掉 | 主線鉤子：姐姐失蹤的原因 |
| 走廊協尋影印紙 | 三年一班學生校慶當日失蹤 | 印證字條：失蹤的是姐姐 |
| 走廊盡頭鐵門 | 通往頂樓，鎖死，門把纏舊紅線 | 印證黑板：頂樓是事件現場，也是下一章的路 |

**相互印證檢查（過）**：每條線索都有另一條線索與它相扣，沒有孤立的線索。土丘（地貌）印證公告欄（歷史）；協尋紙（姐姐）印證字條（姐姐在查的事）；鐵門（頂樓）印證黑板（跳樓地點）。

**誤導與死胡同檢查（過，附一個注意點）**：玩家不會被引到無解的路。鐵門打不開是刻意的（第一關不該上頂樓），文案寫明「鎖死、紅線」，是預告不是死胡同。注意點：實際玩的人會不會在鐵門前停太久、誤以為要找鑰匙，這個我驗不到，要老闆試玩時看他卡不卡。

## 二、標準 4：反派塑造與線索一致性

- **外觀**：制服長髮女生剪影。黑板鋪陳的正是「跳樓的女學生」，吻合（過）。
- **出沒位置**：第一關只在終幕現身一次，出現在走廊盡頭、通往頂樓的鐵門旁。黑板的鋪陳就是「從頂樓跳下」，她守在頂樓入口，吻合（過）。
- **行為動機**：她的死引爆地底積存的陰氣（公告欄鋪陳來源）、她的怨纏著查她名字的人（字條鋪陳姐姐為什麼失蹤）。玩家收齊三條主線線索後她才現身，等於「查到她的名字」才招來她，吻合（過）。
- **殘留線索與突發危機的關係（過）**：終幕突現之前，玩家手上已有足夠線索理解她是誰；她不是憑空跳出的嚇人道具。

## 三、驗不到、留給老闆試玩的部分（對標準 1、3）

- 漸進壓迫感的實際強度：開場安靜、心跳加速、燈閃的節奏，真人玩起來是不是真的步步為營。
- 剪影突現的驚嚇強度會不會過頭或不夠。
- 視野限制會不會太暗讓人迷失、或太亮不夠緊張。
- 手機觸控（按住拖曳）未經實機測試，老闆用手機開一次即可確認。
