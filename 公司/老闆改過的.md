# 老闆改過的

公司在這裡記老闆的改動：日期、改了什麼、老闆說的理由。

---

- 2026-11-14　公司名從「默毀」改成「不義」，遊戲名一起改。老闆的理由：那個男方最被記住的就是他的不義（沒跳、留下她一個人走完），這個名字就是故事的核心。
- 2026-11-14　彩蛋從「公司名當地址」改成「協尋影印紙上印的名字（不義）」。老闆的理由：不想用地址了，名字直接印在紙上。
- 2026-11-14　姐姐的存在感：不顯靈帶路，改成隨著學校深入與接近屍身慢慢變明顯。老闆說的設定：姐姐是無辜被波及的，她的提示引導自己被藏起的屍身和女主的逃生方向。
- 2026-11-14　姐姐被盯上的原因落成線索：書桌抽屜的筆記本殘片，寫殉情那年管訓導的主任說過姐姐長得像男方。老闆說的設定：姐姐與殉情的男方長得極為相似。
- 2026-11-14　協尋紙：樓梯間口 3 張、地上 2 張；姐姐那張姓「鍾」看得清楚、名字被水漬暈開（老闆定的姓；女主角姊妹姓鍾）。
- 2026-11-14　第一關不做逃生，逃生設計留給之後的關卡。老闆確認的。
- 2026-11-14　試玩回報：重新開始按鈕沒動靜。原因：頁面重載被預覽／中控台環境擋住。第二版改成遊戲內重置。
- 2026-11-15　第二版試玩回報：重新開始還是沒變化。真正病因在公司的 CSS：結束畫面的層寫了 display:flex，壓過 hidden 屬性，結束畫面從開場就一直蓋住整個畫面（玩家根本還沒進到遊戲）。第三版加 `[hidden]{display:none!important}` 修掉，並把自檢方法從「讀狀態」改成「看實際渲染＋真實點擊」。
- 2026-11-15　第三版試玩：畫面長寬比確認沒問題（不動）；提出線索要能重複查看，第四版做成筆記（看過的線索自動抄進去，右上角鈕或 L 鍵開，點條目重看原文）。
- 2026-11-15　第四版試玩評語：有緊張感（標準 1、3 過）；終幕現身的她符合線索（標準 4 過）；但姐姐的存在感「不明顯，甚至完全察覺不到」。第五版把存在感改成三層分層設計，並加走進中間教室的引導提示。
- 2026-11-15　第五版複驗後老闆說「好，準備交給客人」，第一關定案；交辦把之前提過的後續想法（頂樓、逃生、事件節奏、手機實測、公開發行）寫進報告，做成 成品/不義-後續規劃報告.md，這一週不做。
- 2026-11-15　交給客人的方式改了：玩的人是同學、用電腦打開；上傳路從 Netlify Drop 改成 GitHub Pages。老闆的理由：要長期保存，不要一小時後消失的那種。
- 2026-11-15　老闆說不用收同學的感想。成品上線交出去就到「已交出去」為止，不等同學回報；驗收證據就落在老闆自己的試玩上（標準 1、3、4 都是老闆親玩給的評語）。
